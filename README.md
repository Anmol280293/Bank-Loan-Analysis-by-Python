# Bank Loan Analysis (Python)

##  Project Overview

Built an end-to-end **Loan Analytics Solution using Python** to analyze lending performance, borrower behavior, and financial risk. Utilized **Pandas, NumPy, and visualization libraries** to transform raw loan data into actionable insights and business-driven metrics.

---

##  Business Problem

Financial institutions need to:

* Track **loan applications and funding trends**
* Identify **good vs bad loans**
* Monitor **repayment performance**
* Analyze borrower risk using **DTI & interest rates**

---

##  Objective

* Build a **data-driven analytics pipeline**
* Calculate **core financial KPIs**
* Perform **risk segmentation (Good vs Bad Loans)**
* Generate **visual insights for decision-making**

---

##  Tech Stack (Python Only)

* **Python**
* **Pandas** → Data Cleaning & Transformation
* **NumPy** → Numerical Computation
* **Matplotlib / Seaborn** → Data Visualization
* **Jupyter Notebook** → Analysis Workflow

---

##  Key KPIs Implemented

*  Total Loan Applications (MTD)
*  Total Funded Amount
*  Total Amount Received
*  Average Interest Rate
*  Average Debt-to-Income (DTI) Ratio

###  Good Loan Metrics

* Good Loan %
* Total Good Loans
* Funded Amount (Good Loans)
* Amount Received (Good Loans)

###  Bad Loan Metrics

* Bad Loan %
* Total Bad Loans
* Funded Amount (Bad Loans)
* Amount Received (Bad Loans)

---

## 🔍 Data Analysis Workflow

### 1️ Data Cleaning

* Handled missing values
* Standardized column formats
* Converted date columns for time-series analysis

### 2️ Feature Engineering

* Created **MTD metrics**
* Derived **Good vs Bad Loan flag**
* Calculated **DTI ratios & aggregated KPIs**

### 3️ Exploratory Data Analysis (EDA)

* Monthly loan trends
* Regional distribution
* Loan purpose breakdown
* Employment length impact
